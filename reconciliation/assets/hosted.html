                How to read the comparison
                
        
                  Correctness is agreement with author-written draft labels on
                  fictional examples, not independently validated production
                  accuracy. Per-case details show expected decisions and

                  timing alone does not describe reliability.

                  Evidence before a decision
                  
        How this works
        
                  
        
                    Matching is exact. The assistant investigates. You decide
                    what happens next.
                  
        
                
        
              
        
              
        
                
        
                  1
                  
        Compare the records
        
                  
        
                    Ordinary code compares each invoice and currency using exact
                    decimal amounts. It keeps duplicates and missing records
                    visible. It does not guess an exchange rate or why a balance
                    changed.
                  
        
                
        
                
        
                  2
                  
        Investigate with evidence
        
                  
        
                    Google ADK gives Gemini a small set of tools for the
                    selected supplier and statement. Answers link to source
                    rows. Hotel-response proposals must quote the original reply
                    and cite an invoice the agent has read.
                  
        
                
        
                
        
                  3
                  
        Make the human decision
        
                  
        
                    You inspect the evidence and confirm follow-up. Hotel claims
                    stay labelled as unverified. The assistant cannot change a
                    balance, send a supplier message, authorise payment or
                    confirm its own work.
                  
        
                
        
              
        
              
        
                
        
                  What Google ADK does
                  
        
                    ADK runs the agent's tool calls. The question agent reads
                    statement evidence; the hotel-response agent reads the
                    original reply and exact invoice references. They submit
                    structured selections. Server code validates them and
                    supplies the financial wording and permitted next steps.
                  
        
                  
        
                    Each question or reply analysis has a limit of four model
                    requests and a sixty-second deadline. Tool requests are
                    bounded too. These limits help stop a single task running
                    indefinitely.
                  
        
                
        
                
        
                  How records survive a refresh
                  
        
                    The app saves statement sources, questions, hotel replies
                    and human follow-up in private Google Cloud Storage.
                    Original statement reports and recorded reviews are kept
                    separate from later follow-up. Storage version checks stop
                    an older screen from overwriting newer work.
                  
        
                  
        
                    Repeated submissions reuse their saved request reference. An
                    interrupted model request stays marked unconfirmed;
                    refreshing does not automatically run it again.
                  
        
                
        
                
        
                  What happens when something fails
                  
        
                    Provider errors, unfinished answers and unavailable checks
                    remain visible. An answer that fails validation produces no
                    actionable proposal. Your saved sources remain available. A
                    case stays unchanged until an explicit follow-up save
                    succeeds.
                  
        
                  
        
                    Activity shows recorded tool actions rather than hidden
                    reasoning. Quality separates checks on this statement from
                    the original sample evaluation results, including their
                    failures.
                  
        
                
        
                
        
                  Access, data and model use
                  
        
                    This workspace uses a shared password and expiring
                    server-side sessions. The shared password does not identify
                    individual people; recorded names are self-reported. Secrets
                    stay on the server. Saved correspondence is visible to
                    everyone who has workspace access.
                  
        
                  
        
                    Analysis sends the entered reply and selected invoice
                    evidence to the configured Gemini service. Use fictional or
                    anonymised records here. Asking or analysing uses the shared
                    daily request allowance. It is a request limit, not a
                    guaranteed spending cutoff.
                  
        
                
        
                
        
                  What is simulated here
                  
        
                    Hotel, booking and finance records are fictional. The
                    finance-service integration and recovery examples
                    demonstrate the workflow without connecting to a real hotel
                    or accounting system. A real rollout would need company
                    sign-in, individual audit identities, retention rules and
                    approved supplier/finance connections.
                  
        
                  
        
                    This app uses Google ADK, Gemini, Cloud Run and Cloud
                    Storage. It does not claim to be an official loveholidays
                    system or to have measured business savings.
